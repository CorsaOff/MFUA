# Отчет: Попытка развертывания Jira Software в Docker

## 1. Описание задачи
Запуск платформы Jira на порту 2990 с использованием образа:
`docker run -d --name jira -p 2990:8080 addono/jira-software-standalone`

## 2. Ход работы и возникшие сложности
После запуска контейнера был инициирован мониторинг логов командой `docker logs -f jira`. 

### Выявленные проблемы:
1. **Длительная инициализация:** В течение 10 минут приложение не перешло в статус "Ready".
2. **Сетевая ошибка:** При попытке открыть `http://localhost:2990` браузер выдает "Страница недоступна" или "Превышено время ожидания".
3. **Ошибки в логах:** В терминале наблюдаются ошибки типа `OutOfMemoryError` или цикличные перезапуски сервиса.

## 3. Анализ причин
Вероятные причины неудачного запуска:
- **Недостаток RAM:** Для стабильной работы Jira требуется минимум 2-4 ГБ свободной оперативной памяти, выделенной под Docker.
- **Таймаут:** Приложению потребовалось больше времени на создание внутренней структуры БД, чем было отведено на проверку.


## 4. Вывод
На текущей конфигурации системы запуск Jira в Docker не удался из-за ресурсных ограничений. Для успешного развертывания требуется увеличить лимиты памяти в настройках Docker Desktop (Settings -> Resources).
